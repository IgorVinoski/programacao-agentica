# programacao-agentica

Trabalho final de Programação Agêntica (IFSul Passo Fundo, Prof. Élder Bernardi).

**Tema:** um "mini-Astra", ou seja, agentes que tentam provar problemas de Erdős e verificam a prova em Lean 4, e o que acontece com quem opera esse fluxo.

- `proposta.md`: pergunta, hipótese, cenário e forma de observação
- `registro/`: diário e tabela de problemas (previsões commitadas antes de cada etapa)
- `docs/estado-da-arte.md`: fontes sobre IA em provas matemáticas (2025–2026)
- `produto/`: o harness e as formalizações em Lean
- `artigos/`: artigo de cada integrante, em PDF (modelo SBC)

Não colocar senhas, tokens nem credenciais neste repositório.
